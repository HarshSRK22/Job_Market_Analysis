# Job Market Analysis

## Project Overview

This project analyzes job-market data to identify trends in
job roles, salaries, industries, locations, education
requirements, and technical skills.

## Dataset

- 742 job postings
- 41 features

## Tools & Technologies

- SQL
- Python
- Excel
- Power Bi

## Key Analysis

- Job title demand
- Salary analysis
- Industry-wise job distribution
- Location-wise job opportunities
- Company hiring activity
- Education vs salary
- Seniority vs salary
- In-demand technical skills
- Skills associated with salary

## Key Insights

- Data Scientist was the most frequent job title.
- California had the highest number of job postings.
- Python, Excel and SQL were the most frequently required skills.
- Salary varied across education and seniority levels.
